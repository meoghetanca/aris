# Messaging

Every message traces back: **persona -> pain -> evidence -> benefit -> proof -> CTA.**
A message that cannot name the pain it answers is a slogan.

## The chain, per message

```json
{ "id": "MSG-001", "priority": 1, "message": "", "benefit": "", "proof": "",
  "cta": "", "evidence": ["PAIN-003"] }
```

`proof` is what makes the benefit credible, and it must be something that exists: a
number you can cite, a mechanism you can describe, a guarantee you can honour.
Where there is no proof, say `unknown` and let the message stand on the mechanism
alone — an unproven benefit stated as proven becomes an unsupported claim in an asset
and the claim gate will catch it there, later and more expensively.

## Hierarchy means priority

`priority: 1` is the one thing a person remembers. There is exactly one per persona.
If two messages are both priority 1, the hierarchy has not been decided.

## Benefits versus features

```
Feature:  real-time sync across tools
Benefit:  the data is right when someone asks, without anyone exporting anything
```

The benefit states what changes for the person. "Increases efficiency" is neither —
it is a category of benefit, not a benefit.

## Glossary-bound

Build `glossary` from the sector entry's `reservedTerms` plus the terms this product
needs. Then use those terms and only those terms: one concept, one word, across every
asset. Drift between "workspace", "project" and "board" for the same object reads as
three features.

## Tone of voice

A decision, not a derivation — it is taste and brand. Offer options built from the
sector norms and the chosen positioning, each written as the **same sentence in that
tone** so the difference is visible rather than described. Record what was chosen.

## Length realism

Write copy at the length it will actually be used: a headline that must fit a hero, a
subject line under fifty characters, an ad headline at the platform's limit. Copy
written without its constraint gets cut by whoever pastes it in, and the cut version
is the one that ships.
